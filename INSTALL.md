# Install Solitaire

After [setting up PrimitiveOS](https://github.com/DoanNguyenTrong/kindle-primitive-launcher/blob/main/docs/INSTALL.md#first-time-setup-over-usb), open **Store** from Primitive Launcher.
Select **Solitaire** under **Apps**, tap **Get**, then open it from the Launcher grid.

For a local USB test, extract the package for your Kindle, copy the `solitaire` and `documents` folders to user storage,
eject, and open Solitaire from Primitive Launcher. The app uses the launcher's fonts. The Done button returns you
to the launcher.
